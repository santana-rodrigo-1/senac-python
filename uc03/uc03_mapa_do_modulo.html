Projeto final integrador

Um sistema web em Django escolhido por cada grupo, reunindo toda a UC: models e banco via ORM, área administrativa, autenticação por níveis, front-end integrado com Bootstrap e conteúdo publicado — versionado no GitHub. Simula uma entrega real da JWC.

Indicadores da UC

  1. Configura o ambiente de desenvolvimento.
  2. Estrutura algoritmos pela lógica computacional.
  3. Cria código back-end conforme o projeto.
  4. Trata requisições POST e GET do front.
  5. Implementa session e cookies.
  6. Integra banco de dados à aplicação.
